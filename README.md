# Матрёшка — прототипы интерфейса

Живые макеты десктопного приложения. Открываются по адресу
`https://matryoshka-labs.github.io/matryoshka-design/`

## Что внутри

`index.html` — один самодостаточный файл. Содержит три варианта флоу подтверждения
изменения (OPP-2041), по три шага каждый:

| Вариант | Идея |
|---|---|
| `1a` | Единая лента — доказательства, решение и квитанция в переписке |
| `1b` | Лента и инспектор — решение в правой панели |
| `1c` | Момент решения — отдельный лист подтверждения |

Переключатели сверху меняют дизайн-систему (Apple HIG ↔ Fluent 2) и тему
(светлая ↔ тёмная) сразу во всех девяти экранах.

## Как оставить замечание

Вкладка **Issues** этого репозитория. В заголовке укажите номер варианта и шаг,
например: `1b, шаг 2 — панель решения слишком узкая`.
