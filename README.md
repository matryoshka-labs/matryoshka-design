# Матрёшка — прототипы интерфейса

Живые макеты десктопного приложения:
`https://matryoshka-labs.github.io/matryoshka-design/`

## Что внутри

`index.html` — один самодостаточный файл, интернет для работы не нужен.
21 экран, семь разделов (вкладки сверху):

| Раздел | Что показывает |
|---|---|
| `3a` | Менеджер моделей: список слева, настройки справа, «＋» у раздела |
| `3b` | Тот же менеджер как раздел настроек во весь экран |
| `3c` | Тот же менеджер карточками с вкладками |
| `2a` | Поле ввода: ассеты, модели, уточняющие вопросы, профиль |
| `1a` | Подтверждение изменения — всё в переписке |
| `1b` | Подтверждение изменения — решение в правой панели |
| `1c` | Подтверждение изменения — отдельный лист подтверждения |

Переключатели справа меняют дизайн-систему (Apple HIG ↔ Fluent 2) и тему
(светлая ↔ тёмная) — макет перестраивается целиком. Шаги внутри раздела
листаются стрелками ← →.

## Как оставить замечание

Вкладка **Issues** этого репозитория. В заголовке укажите раздел и шаг,
например: `1b, шаг 2 — панель решения слишком узкая`.
