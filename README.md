# Матрёшка — прототипы интерфейса

Живые макеты десктопного приложения:
`https://matryoshka-labs.github.io/matryoshka-design/`

## Что внутри

`index.html` — один самодостаточный файл, интернет для работы не нужен.
Три варианта флоу подтверждения изменения (сценарий OPP-2041), по три шага каждый:

| Вариант | Идея |
|---|---|
| `1a` | Единая лента — доказательства, решение и квитанция в переписке |
| `1b` | Лента и инспектор — решение принимается в правой панели |
| `1c` | Момент решения — отдельный лист подтверждения поверх окна |

Переключатели в верхней панели меняют дизайн-систему (Apple HIG ↔ Fluent 2)
и тему (светлая ↔ тёмная) — макет перестраивается целиком.
Шаги листаются стрелками ← →.

## Как оставить замечание

Вкладка **Issues** этого репозитория. В заголовке укажите вариант и шаг,
например: `1b, шаг 2 — панель решения слишком узкая`.
